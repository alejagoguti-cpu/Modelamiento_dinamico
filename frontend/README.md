# frontend

Carpeta para todos los activos de la interfaz de usuario (páginas estáticas, hojas de estilo, scripts y recursos estáticos).

Contenido recomendado:

- index.html, demo.html, modulo-*.html
- style.css, demo.css, modulo-*.css, network06-shared.css
- scripts.js, modulo-02.js, modulo-03.js, modulo-04.js, modulo-05.js, modulo-06.js, modulo-07.js, modulo-08.js
- assets/ (imágenes, iconos y otros recursos)

Notas:
- Tras mover los archivos aquí, revisa las rutas relativas (por ejemplo, referencias a `./style.css` o `./assets/...`).
- Si prefieres, puedo copiar los archivos aquí y actualizar automáticamente las rutas en los HTML; indica si quieres que lo haga ahora.
