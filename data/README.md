# data

Carpeta para almacenar conjuntos de datos y capas geoespaciales.

Archivos sugeridos:

- *.geojson, *.GEOJSON (barrios_bogota.geojson, upz.geojson, red_eep.geojson, vias.geojson, etc.)
- Resultados de procesamiento (CSV/GeoPackage/Parquet)
- Documentos de respaldo (PDFs relacionados con los datos)

Notas:
- Algunos archivos en el repo actual (por ejemplo `upz.geojson`, `barrios_bogota.geojson`, `red_eep.geojson`) son candidatos claros para moverse aquí.
- Mantener los datos crudos separados de los derivados facilita reproducibilidad.
