# Reorganization README

Este commit reorganiza la estructura del repositorio en dos niveles principales:

- frontend/: HTML, CSS, JS y assets estáticos para la interfaz.
- data/: GeoJSON y otros datasets.
- backend/: código de servidor (si existe).
- apis/: especificaciones y endpoints relacionados con APIs.

Se han actualizado rutas relativas en los archivos HTML y CSS para que apunten a la nueva ubicación de los assets.
