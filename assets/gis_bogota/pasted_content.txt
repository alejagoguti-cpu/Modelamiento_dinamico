Quiero construir una simulación urbana de Bogotá que represente cómo el **ruido urbano puede modificar el desplazamiento y la conectividad funcional de la avifauna**, utilizando como especie de referencia la **mirla patinaranja (*Turdus fuscater*)**.

Voy a proporcionarte varias capas GIS de Bogotá, incluyendo cobertura vegetal/hábitat, humedales, arbolado, espacios verdes y posteriormente una capa de ruido.

RUIDO

## OBJETIVO DEL MODELO

El objetivo es simular cómo un cambio en la intensidad del ruido modifica la facilidad de desplazamiento de *Turdus fuscater* entre diferentes parches de hábitat urbano.

La pregunta que debe responder el modelo es:

**¿Cómo cambia la conectividad funcional del paisaje para *Turdus fuscater* cuando aumenta la perturbación acústica?**

No presentes las rutas como trayectorias reales de individuos. Es un **modelo conceptual de desplazamiento potencial** basado en resistencia espacial.

## 1. CONSTRUIR EL HÁBITAT

Utiliza las capas GIS que proporcionaré para identificar:

* parques;
* arbolado;
* coberturas vegetales;
* humedales;
* cuerpos de agua pertinentes;
* otras áreas verdes relevantes.

Agrupa estas coberturas para construir una primera capa de **hábitat potencial / parches de conectividad**.

NO inventes geometrías.

NO cambies la ubicación de las capas.

Conserva el sistema de coordenadas y la escala espacial de los datos originales.

## 2. CONSTRUIR LA MATRIZ DE RESISTENCIA

El territorio entre los parches debe representarse como una superficie de resistencia.

Conceptualmente:

* vegetación y zonas arboladas → baja resistencia;
* parques y corredores verdes → baja resistencia;
* vegetación dispersa → resistencia intermedia-baja;
* áreas urbanas residenciales → resistencia intermedia;
* tejido urbano denso → resistencia alta;
* grandes vías y superficies muy impermeables → resistencia alta.

Los valores numéricos NO deben inventarse como si fueran mediciones biológicas. Si no existe un valor publicado específico para *Turdus fuscater*, utiliza valores normalizados como parámetros del modelo y deja claramente indicado que son supuestos de simulación.

## 3. INCORPORAR EL RUIDO

Cuando incorpore la capa de ruido, conviértela en un factor que modifique la resistencia.

Usa una relación conceptual:

R_total = R_cobertura × F_ruido

donde:

R_cobertura = resistencia base de la cobertura

F_ruido = factor de perturbación acústica.

El ruido debe aumentar progresivamente la resistencia.

Ruido bajo → poca modificación.

Ruido medio → aumento moderado de resistencia.

Ruido alto → aumento fuerte de resistencia.

Ruido muy alto → comportamiento cercano a una barrera.

NO hagas una relación binaria donde las aves simplemente desaparezcan cuando hay ruido.

## 4. COSTO DE DESPLAZAMIENTO

Para las posibles rutas entre parches utiliza:

C = Σ(R_i × d_i)

donde:

C = costo acumulado de la ruta;

R_i = resistencia de cada celda;

d_i = distancia recorrida.

Las aves deben tender a utilizar rutas de menor costo acumulado.

Sin embargo, NO quiero que todas las aves utilicen exactamente la misma ruta. Deben existir múltiples rutas potenciales y pequeñas variaciones individuales.

## 5. TEORÍA DE CIRCUITOS / MÚLTIPLES RUTAS

Utiliza como referencia conceptual la metodología de teoría de circuitos aplicada a conectividad de aves urbanas.

No quiero representar una única "ruta correcta".

Quiero mostrar una red de rutas potenciales donde algunas zonas funcionan como corredores de mayor importancia.

Visualmente, los corredores con mayor flujo potencial pueden aparecer con mayor intensidad, mientras que las zonas de alta resistencia funcionen como barreras.

## 6. ANIMACIÓN

Una vez construidas las capas y el modelo, genera una animación temporal.

### ESCENARIO 1 — RUIDO BAJO

Las aves se desplazan entre los parches verdes utilizando varias rutas.

Debe existir conectividad relativamente alta.

### ESCENARIO 2 — AUMENTO DEL RUIDO

Incrementa progresivamente el ruido.

Las aves cercanas a las zonas de mayor perturbación deben comenzar a desviarse.

### ESCENARIO 3 — RUIDO ALTO

Las zonas de alta perturbación se convierten en sectores de alta resistencia.

Las aves deben buscar rutas alternativas.

Algunas conexiones deben volverse menos utilizadas.

### ESCENARIO 4 — NUEVO EQUILIBRIO

Las aves se concentran en determinados corredores de menor resistencia.

Quiero que se pueda observar cómo algunos corredores adquieren mayor importancia mientras otros pierden conectividad.

## 8. EXPERIMENTO DE INTERVENCIÓN

## 9. RESILIENCIA

Observa si las aves:

* regresan a sus rutas iniciales;
* mantienen las rutas alternativas;
* o generan una nueva configuración de conectividad.

Esto permitirá representar conceptualmente la **resiliencia del sistema**.
